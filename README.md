# 拾光导航 · LinkNest

一个零运行时依赖、数据保存在浏览器中的个人导航站，支持桌面、手机和深浅主题。

## 功能

- 默认保留十个科研分类，不预置任何网址。
- 点击「添加分类」独立创建分类，空分类也会保存。
- 选择分类后点击「在此分类添加网址」，自动选中当前分类；顶部也可添加网址。
- 网址支持编辑、移动分类、删除、设为常用和关键词搜索。
- 刷新后保留新增数据，同源标签页同步。
- JSON 备份包含所有分类及网址，支持合并与替换。同分类中的重复网址会跳过。

## 2.0 升级

按本次清空要求，首次加载新版会清空旧版网址和收藏，只保留分类名称，并移除旧期刊分区数据。之后新增的网址不会在刷新时再次清空。

新版使用 linknest.workspace.v2，仅接受版本 2 备份。旧版备份不会恢复旧网址。损坏的新版数据不会被自动覆盖，可通过有效备份替换恢复。

## 本地运行

需要 Node.js 22 或更新版本，无需安装依赖。

```sh
node scripts/serve.mjs
```

打开 [本地导航站](http://127.0.0.1:4173)。直接双击 HTML 可能被浏览器阻止加载模块。更新后按 Ctrl+F5 刷新。

```sh
npm test
npm run check
node scripts/validate-backup.mjs your-backup.json
```

## 隐私与限制

数据不上传服务器或 GitHub，不同浏览器、设备和站点地址不自动同步。清除浏览器数据会丢失导航，请定期「导出我的导航」。最多 100 个分类、2000 个网址，备份上限 2 MB。

无统计脚本、第三方字体或模型 API。添加网址后从该网站原站请求 /favicon.ico，不发送页面来源；失败显示备用标识。仅支持不含账号密码的 HTTP/HTTPS 地址，项目不检查目标网站可信度。

## 项目

[GitHub 仓库](https://github.com/CX330FGT/-linknest-)。

dist/ 是完整静态网站。core.js 管理校验、迁移、搜索与合并，app.js 管理交互，icons.js 生成原站图标路径。仓库发布与网站上线是独立步骤；Pages 工作流需要拥有者启用 Pages 后手动执行。
