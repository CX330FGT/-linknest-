# 网站图标

`dist/icons.js` 包含 92 个不同域名的本地图标，覆盖全部科研目录和旧版示例收藏。相同网站的不同页面复用一个图标，例如同一出版平台的期刊共享平台图标。图标只用于识别对应网站或项目，不表示关联或背书，相关权利归各自权利人，不随本项目代码的 MIT 许可证重新授权。

图标来自网站公开 favicon、项目/机构标志以及公开品牌图标库。各项来源与日期见 [icon-sources.json](icon-sources.json)。原始图片按比例转换为 64px PNG，未重绘标志；页面采用 28px 图片和白色底板，在深浅主题下保持辨识度。

浏览预置条目不向图标服务发送请求。个人收藏按网址匹配内置图标，无需升级收藏数据。未知网站尝试加载其原站 `/favicon.ico`，不会把收藏路径、查询或片段发送给图标服务，也不会发送页面 referrer。新网站若没有标准 favicon 或网络不可达，会显示备用标识；不保证任意自定义网站都能成功加载图标。
